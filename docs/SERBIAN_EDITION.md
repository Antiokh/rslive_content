# Сербская редакция RSLive

`/sr/` — не полный перевод русской энциклопедии, а отдельная выборочная редакция для сербской аудитории.

## Что публикуем

- самостоятельные инструкции, которые русскоязычный пользователь может отправить сербскому владельцу жилья, работодателю, врачу, бухгалтеру или другому контрагенту;
- объяснения о русской миграции и сообществах в Сербии, когда тема полезна сербскому читателю;
- культурный контекст RSLive и русскоязычной аудитории;
- материалы, где наличие сербской версии непосредственно уменьшает языковой барьер при реальной процедуре.

## Что не делаем

- не переводим автоматически всю энциклопедию;
- не создаём `/sr/`-страницы только ради симметрии маршрутов;
- не показываем русский материал под сербским URL как fallback;
- не заставляем сербскую страницу ссылаться на русские статьи для выполнения основной процедуры.

## Навигация

Сербское меню должно строиться только из реально опубликованных `/sr/**` материалов. Главная точка входа — `/sr/`.

Определение языка браузера допустимо только как мягкая помощь: автоматический переход на `/sr/` выполняется с корневой страницы при сербском языке браузера и только если пользователь ранее явно не выбрал язык. Ручной выбор имеет приоритет и запоминается в браузере.

## Контент

Каждая сербская инструкция должна быть самостоятельной. Если русская статья содержит кнопку «показать сербу», она должна вести на каноническую сербскую страницу вместо хранения второй длинной копии инструкции внутри русской статьи.
