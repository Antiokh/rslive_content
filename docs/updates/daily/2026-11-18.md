# Обновления за 18.11.2026

- [Карта русскоязычных бизнесов в Сербии](/map/russian-businesses/) — Обновили общую карту до 254 физических точек, из которых для 100 подтверждена связь с ALTA. Добавили проверенные PROKUDNIK.CUTS, Volna, HookahPlace Belgrade, NODA SPACE, MARE beauty loft и WRRRAPs; уточнили адрес и реквизиты Nomad Bar. Отделили банковские счета от эквайринга: для трёх точек Julianna/Kofilin подтверждён PaySpot, для O’nigiri — AltaPay на дату ответа владельцев.
- [«Ковчег Бизнес»: карта предприятий после ALTA banka](/map/ark-business/) — Сверили обновлённую карту «Ковчега»: из 129 точек 114 сопоставлены с опубликованными заведениями, 15 ждут проверки. Девять новых записей связаны с существующими карточками без повторного добавления; ещё шесть бизнесов опубликованы после проверки.
- [Русскоязычные бизнесы в Сербии](/adaptation/russians/business/) — Добавили шесть проверенных бизнесов с публичными адресами и реквизитами, уточнили карточку Nomad Bar и обновили сведения о связи заведений с ALTA.
