# Обновления за 28.11.2026

- [Банки и финансы](/arrival/bank/) — Объяснили, когда банк обязан отказать в базовом счёте: если не может выполнить обязательные проверки клиента. Уточнили, что высокий страновой риск требует усиленной проверки, а не автоматического отказа.
- [Санкции против России и ограничения для россиян в Сербии](/gov/sanctions/) — Объяснили, почему банки усиливают проверки клиентов, связанных с Россией: перечень стран высокого риска ЕС, правила европейских банковских групп, ограничения налогового обмена и границы отказов по общим критериям риска.
