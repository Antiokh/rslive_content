# Обновления за 17.08.2026

За этот календарный день подготовлены такие содержательные изменения:

## Формы ведения бизнеса в Сербии

[Открыть статью](/arrival/business/types/)

- Исправили модель PDV для услуг иностранным клиентам: калькулятор теперь учитывает место реализации услуг, не применяет сербский PDV и порог 8 млн RSD к потоку с местом реализации вне Сербии, сохраняя отдельный лимит 6 млн RSD для paušal.

## PDV

[Открыть статью](/gov/taxes/business/pdv/)

- Уточнили состав оборота для порога 8 млн RSD и правила места реализации услуг: типичная B2B-услуга иностранной компании обычно не облагается сербским PDV и не входит в этот порог, но иностранный платёж сам по себе такого результата не даёт.
