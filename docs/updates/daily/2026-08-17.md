# Обновления за 17.08.2026

За этот календарный день подготовлены такие содержательные изменения:

## Визаран

[Открыть статью](/arrival/visarun/)

- Перепроверили миграционные, пограничные, налоговые и шенгенские правила; убрали «50/50» на шенгенской границе, общий трёхмесячный допуск к работе и неверный штраф за просрочку.
- Электронную регистрацию отделили от практического совета сохранять бумажный белый картон для банков и других учреждений.
- Добавили практические ограничения жизни без РВП: банки, ПМЖ, автомобиль, водительские права и налоговое резидентство Сербии.

## Банки и финансы

[Открыть статью](/arrival/bank/)

- Развели требования НБС и фактический онбординг: туристу без РВП на новый сербский счёт сейчас не рекомендуем рассчитывать, если банк заранее письменно не подтвердил обратное.
- Сохранили полезные процедуры и добавили бумажный белый картон как практический документ для визита в банк.

## API Banka

[Открыть статью](/arrival/bank/apibanka/)

- Убрали устаревшую рекомендацию API Banka как предсказуемого варианта без РВП; официальный нерезидентский продукт не считаем гарантией открытия туристу.
- Сохранили документы, карты, тарифы, SWIFT и ограничения электронного банкинга.

## Adriatic Banka

[Открыть статью](/arrival/bank/adriatic/)

- Убрали Adriatic Banka из надёжных вариантов открытия счёта туристу без РВП и отделили существование нерезидентского продукта от фактического одобрения клиента.
- Сохранили документы, карты, мобильный банк, SEPA и SWIFT; без РВП рекомендуем сначала получить письменное подтверждение банка.
