# Обновления за 24.08.2026

За этот календарный день опубликованы такие содержательные изменения:

## Приложение и офлайн-режим

[Открыть статью](/about/app/)

- Добавили простое объяснение установки RSLive как приложения, отдельного скачивания офлайн-копии, экономного обновления только изменившихся файлов, автообновления, работы без сети и удаления офлайн-данных.

## Политика конфиденциальности

[Открыть политику](/about/privacy/)

- Перенесли сведения о конфиденциальности из отдельного `/cookie/` в раздел «О проекте» и собрали на одной странице cookies, `localStorage`, `sessionStorage`, Cache Storage, настройки приложения и офлайн-копии, внешнюю аналитику, сроки хранения, удаление локальных данных и обращения по персональным данным.
- Убрали устаревшую модель пользовательской авторизации и отдельные страницы banner/delete: старые URL сохраняются только как совместимые редиректы на единую политику.
