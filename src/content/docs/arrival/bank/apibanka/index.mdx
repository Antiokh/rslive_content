[API Banka a.d. Beograd](https://www.apibank.rs) — сербский коммерческий банк, который имеет отдельную процедуру обслуживания международных клиентов и физических лиц-нерезидентов.[^1]

Банк участвует в системе страхования вкладов Республики Сербия: гарантия составляет до 50 000 EUR на одного вкладчика.[^2]

<Aside type="note" title="Счёт без РВП">
  По состоянию на 7 августа 2026 года API Banka остаётся одним из банков, чьи официальные материалы прямо предусматривают счета и отдельные тарифы для **физических лиц-нерезидентов**. После изменений правил НБС от июля 2026 года это особенно важно для иностранцев без [РВП](/arrival/boravak/).[^1]

  Сам статус нерезидента не гарантирует одобрение: сначала банк проводит предварительную проверку клиента и вправе отказать в установлении деловых отношений.
</Aside>

## Открытие счёта для физических лиц

API Banka предлагает сначала отправить **Zahtev za uspostavljanje poslovnog odnosa za fizička lica** через контактную форму для предварительного одобрения. При положительном решении нужно в течение пяти рабочих дней прийти в отделение для идентификации; иначе заявка считается недействительной.[^1]

### Документы

Базово подготовьте:

- загранпаспорт;
- документ, подтверждающий место проживания;
- идентификационный номер в стране гражданства, если он существует;
- подтверждение источника средств, если банк запросит;
- анкету банка.

Если у иностранца уже есть [РВП](/arrival/boravak/) или [постоянное проживание](/integration/stalni/), после вступивших 18 июля 2026 года поправок НБС заявление на открытие счёта должно также содержать **евиденциони број странца (EBS)**.[^3]

Требуется личная идентификация в отделении.[^1]

## Тарифы для физических лиц

У API Banka действует отдельная **Tarifa naknada za usluge za fizička lica nerezidente**, применяемая с 1 декабря 2025 года. Перед открытием счёта проверяйте текущий PDF на сайте банка: тарифы могут меняться.[^4]

## Открытие счёта для предпринимателей и компаний

### Основные документы

Для зарегистрированного в Сербии бизнеса требования отличаются от счёта иностранного физлица. Для нерезидентных юридических лиц API Banka публикует отдельный перечень документов, включая выписку из иностранного реестра, перевод на сербский, сведения о представителях и бенефициарах и документы о структуре собственности.[^5]

Если компания или предприниматель зарегистрированы в Сербии, уточните актуальный комплект документов непосредственно в банке.

## Счета и карты

Банк предлагает динарские и валютные счета, платёжные карты и электронный/мобильный банкинг. Конкретный набор продуктов зависит от статуса клиента и выбранного пакета.[^1]

## SWIFT и международные переводы

SWIFT: **APIBRSBG**.[^5]

Комиссии за входящие и исходящие международные переводы зависят от действующего тарифа и типа счёта. Для нерезидента используйте актуальную версию тарифа банка, а не старые сохранённые PDF.[^4]

## Когда рассматривать API Banka

- нужен счёт физического лица без РВП;
- нужен банк, официально публикующий процедуру для нерезидентов;
- другие банки требуют EBS или отказали после предварительной проверки.

Перед подачей заявки сравните стоимость обслуживания и международных переводов с [другими банками](/arrival/bank/): наличие нерезидентского продукта не означает, что он будет самым дешёвым.
