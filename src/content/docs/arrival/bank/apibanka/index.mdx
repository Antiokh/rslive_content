[API Banka a.d. Beograd](https://www.apibank.rs/) — небольшой сербский банк с отдельным направлением для международных клиентов. На официальной странице банк по-прежнему описывает открытие счёта нерезиденту без разрешения на проживание и предварительную проверку заявки.[^1]

**Практически на 17 августа 2026 года туристу без РВП не стоит рассчитывать на открытие нового счёта в API Banka.** После июльских изменений требований к идентификации иностранцев прежний маршрут перестал быть достаточно предсказуемым. Официальная страница нерезидентского продукта сохраняется, но фактический онбординг и KYC могут закончиться отказом или требованием статуса, которого у туриста нет.

Банк участвует в системе обязательного страхования депозитов Сербии. Страховое покрытие — до 50 000 EUR на одного вкладчика в одном банке.[^2]

<Aside type="caution" title="Без РВП сначала получите письменное подтверждение">
  Если РВП ещё нет, не идите в отделение только потому, что сайт банка описывает нерезидентский счёт. Сначала отправьте документы на предварительную проверку и попросите подтвердить, что банк готов открыть счёт именно иностранцу **без РВП и без EBS**. Отсутствие отказа или приглашение «подойти и попробовать» не считайте одобрением.
</Aside>

## Как открыть счёт

Если банк подтвердил готовность рассмотреть ваш статус, используйте его официальную процедуру предварительной проверки.[^1]

<Steps>
1. Скачайте **Zahtev za uspostavljanje poslovnog odnosa za fizička lica** со страницы международных клиентов API Banka.
2. Заполните заявление и отправьте его через контактную форму на той же странице.
3. Дождитесь предварительного решения и уточните, достаточно ли вашего текущего миграционного статуса.
4. После положительного ответа придите в отделение **в течение 5 рабочих дней**. Иначе предварительная заявка аннулируется.
5. В отделении пройдите идентификацию, подпишите договоры и уточните, какие именно счета, карты и цифровые сервисы доступны с вашим статусом.
</Steps>

Сам банк указывает ориентир **1–2 рабочих дня** на процедуру открытия счёта нерезиденту после прохождения проверки.[^1] Это официальный ориентир для принятой банком заявки, а не обещание открыть счёт любому нерезиденту.

## Документы

По текущей странице банка базово нужны:[^1]

- действующий загранпаспорт;
- второй документ, в котором указан адрес постоянного или временного проживания;
- заполненная анкета банка;
- для процедуры нерезидента без РВП — подтверждение пересечения государственной границы: штамп/данные в паспорте либо справка пограничной полиции.

Последний пункт остаётся в официальной инструкции API Banka, но сам по себе больше не означает, что турист без РВП пройдёт онбординг.

Банк прямо предупреждает, что по KYC может дополнительно запросить документы об источнике средств.[^1] Практически разумно иметь с собой:

- бумажный [белый картон](/arrival/beli-karton/);
- внутренний паспорт или другой документ с домашним адресом;
- договор аренды в Сербии, если есть;
- трудовой договор, банковскую выписку, налоговую декларацию, договор с заказчиком или иной документ, объясняющий происхождение денег.

Если у вас уже есть [РВП](/arrival/boravak/) или [постоянное проживание](/integration/stalni/), после изменений НБС от 18 июля 2026 года заявление должно содержать **евиденциони број странца (EBS)**.[^3]

## Можно ли открыть удалённо

В документации API Banka предусмотрена процедура открытия через представителя по доверенности.[^1]

Нужны нотариально заверенная копия паспорта клиента, документ с адресом, документы представителя и доверенность. Доверенность должна быть нотариально удостоверена, переведена судебным переводчиком и быть не старше трёх месяцев.[^1]

Наличие этой процедуры не означает, что банк предварительно одобрил клиента: KYC и решение об открытии остаются за банком.

## Счета

API Banka предлагает:[^1]

- динарский счёт в RSD;
- мультивалютный валютный счёт;
- карточные продукты;
- сбережения и депозиты.

Банк отдельно подтверждает, что валютный счёт мультивалютный: для разных валют не требуется открывать отдельный номер счёта.[^1]

## Карты

Для физлиц доступны DinaCard и Visa. По действующему с 1 декабря 2025 года тарифу для нерезидентов:[^4]

| Карта | Основная карта | Практический смысл |
| --- | ---: | --- |
| DinaCard debit | без отдельной платы | платежи преимущественно внутри Сербии |
| Visa Classic debit | без отдельной платы | покупки и снятие наличных в Сербии и за рубежом |
| Visa Infinite debit | 4 000 RSD/мес | премиальный продукт, для обычного счёта нерезидента обычно не нужен |

API Banka пишет, что при открытии валютного счёта Visa выдаётся автоматически и может использоваться в Сербии и за рубежом.[^1]

Снятие дебетовой Visa Classic в банкоматах API Banka по тарифу бесплатно; в банкоматах других банков Сербии — 1% с минимумом 100 RSD, за рубежом — 1% с минимумом 3 EUR. Покупки картой за рубежом облагаются комиссией 1,5%.[^4]

<Aside type="note" title="Не путайте тариф и доступность онбординга">
  Наличие отдельного тарифа для нерезидентов подтверждает банковский продукт, но не право любого нерезидента открыть счёт. Сначала добейтесь одобрения клиента, потом сравнивайте стоимость пакетов.
</Aside>

## Важное ограничение электронного банкинга для нерезидента

На текущей странице международных клиентов API Banka есть существенная оговорка: для оплаты коммунальных и других регулярных счетов через мобильное приложение и E-banking банк указывает необходимость иметь разрешение на проживание и жить в Сербии не менее одного года; до этого банк предлагает проводить такие платежи через отделение.[^1]

При этом тариф для нерезидентов содержит бесплатное обслуживание E-banking и M-banking.[^4] Эти документы описывают разные аспекты услуги и выглядят не полностью согласованными. Поэтому при открытии счёта отдельно спросите сотрудника:

- подключат ли вам mBank/eBank;
- разрешены ли исходящие RSD-платежи;
- можно ли оплачивать счета по IPS QR;
- можно ли делать международные переводы онлайн или только через отделение.

## SWIFT и международные переводы

SWIFT API Banka: **APIBRSBG**.[^1]

По тарифу для нерезидентов:[^4]

| Операция | Комиссия API Banka |
| --- | ---: |
| Входящий перевод в RUB | 0,3%, min 3 000 RSD, max 100 000 RSD |
| Входящий перевод в других валютах до 100 EUR | 1 000 RSD |
| Входящий перевод свыше 100 EUR | 0,3%, min 3 000 RSD, max 100 000 RSD |
| Исходящий валютный перевод | 0,8%, min 3 000 RSD, max 100 000 RSD + корреспондентские расходы при OUR |
| Перевод в RSD в другой сербский банк | 0,8%, min 1 500 RSD, max 40 000 RSD |
| Перевод между своими счетами через e/mBank | без комиссии |

Это дорогой банк для частых международных операций. Сравнивайте его только после того, как банк подтвердил готовность открыть вам счёт.

### Происхождение денег и крупная наличность

Банк прямо пишет:[^1]

- при внесении наличной иностранной валюты свыше эквивалента 10 000 EUR потребуется таможенное подтверждение ввоза либо подтверждение снятия этих средств в другом банке Сербии;
- для входящего перевода лимита как такового нет, но банк может потребовать подтверждение происхождения средств;
- при переводе за границу денег нерезидента, полученных из источника в Сербии, может потребоваться подтверждение уплаты налоговых обязательств.

Если планируется крупная сумма, лучше согласовать документы с банком **до отправки денег**.

## Получение справок для визы и РВП

API Banka подтверждает, что выдаёт справки для виз и оформления разрешения на проживание в отделении.[^1] По тарифу стандартная справка по запросу клиента стоит 1 200 RSD, если для конкретного документа законом или тарифом не предусмотрена бесплатная выдача.[^4]

## Закрытие счёта

Банк прямо указывает, что для закрытия счёта личное присутствие необязательно.[^1] Это полезно, если счёт открывался на время переезда или вы уже уехали из Сербии.

## Практический опыт

Практические обзоры июля 2026 года ещё описывали API Banka как один из наиболее предсказуемых вариантов для иностранца без РВП.[^5] К середине августа этот вывод устарел: наличие официальной нерезидентской процедуры больше не считаем достаточным основанием обещать туристу открытие счёта.

Старые отзывы 2022–2025 годов полезны для понимания сервиса, но не для ответа на вопрос «откроют ли мне сейчас». Решение по новому клиенту проверяйте непосредственно перед подачей.

## Когда выбирать API Banka

API Banka имеет смысл рассматривать, если:

- у вас уже есть РВП/EBS; или
- банк заранее письменно подтвердил готовность открыть счёт при вашем текущем статусе;
- нужна Visa для зарубежных покупок;
- предполагаются редкие, а не постоянные SWIFT-переводы;
- устраивают тарифы и ограничения электронного банкинга.

Если РВП ещё нет и предварительного одобрения тоже нет, не стройте финансовый план вокруг API Banka. Сравните актуальную ситуацию в общем разделе [«Банки и финансы»](/arrival/bank/).
