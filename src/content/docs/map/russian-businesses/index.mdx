## Как устроены данные

Карта использует единый опубликованный набор данных RSLive: проверенные кафе, рестораны, бары и магазины из [карты русских заведений](/map/russian-places/) вместе с дополнительными компаниями из общего каталога. Новые категории появляются на карте по мере проверки их координат. Наличие компании в каталоге или карте не является рекомендацией качества услуг.
