# Политика конфиденциальности

Настоящая политика описывает, какие данные может обрабатывать **RSLive (rslive.ru)**, для каких целей они используются и как можно запросить доступ, исправление или удаление данных.

## Какие данные могут обрабатываться

RSLive может обрабатывать:

- сведения, которые пользователь сам передаёт редакции при обращении, отправке материала или сообщении об ошибке;
- технические данные, необходимые для доставки сайта, диагностики ошибок и защиты инфраструктуры, например IP-адрес, user-agent, время запроса, запрошенный URL и технический результат обработки запроса;
- данные, полученные через внешние API и интеграции, включая Meta Platform, только в пределах предоставленных соответствующей платформой разрешений и для функций, ради которых эти данные были получены.

Для чтения публичных материалов энциклопедии регистрация на сайте не требуется.

## Для чего используются данные

Данные используются только в объёме, необходимом для:

- работы, защиты и технической поддержки сайта;
- ответа на обращения пользователей;
- проверки, обновления и публикации справочной информации;
- работы подключённых интеграций;
- выполнения требований закона, когда такая обязанность применима.

RSLive не продаёт персональные данные пользователей.

## Данные Meta Platform

Если RSLive получает данные через продукты или API Meta, они используются только для заявленной функции соответствующей интеграции и в пределах разрешений, предоставленных Meta.

Такие данные не используются для продажи персональной информации или создания самостоятельных рекламных профилей. Доступ к ним ограничивается объёмом, необходимым для работы интеграции. Данные удаляются или прекращают использоваться, когда они больше не нужны для заявленной цели, когда доступ отозван либо когда удаление требуется применимыми правилами или законом.

## Передача третьим лицам

Данные могут обрабатываться техническими поставщиками, которые обеспечивают хостинг, безопасность, доставку сайта или работу внешних интеграций. Информация также может быть раскрыта, если это прямо требуется законом или обязательным требованием компетентного органа.

## Срок хранения

Данные хранятся не дольше, чем это необходимо для цели их обработки, технической безопасности, разрешения споров или выполнения обязательных требований. Срок хранения технических журналов может зависеть от настроек используемой инфраструктуры и поставщиков услуг.

## Доступ, исправление и удаление

Можно запросить сведения о данных, относящихся к вам, а также их исправление или удаление, если для дальнейшего хранения нет обязательного основания.

Для такого запроса напишите редакции RSLive через [Telegram](https://t.me/rslive_ru). Не публикуйте чувствительные персональные данные в открытых сообщениях или публичных issue.

## Изменения политики

Политика может обновляться при изменении сайта, интеграций или требований к обработке данных. Актуальная версия всегда публикуется на этой странице.
