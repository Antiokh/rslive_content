Выберите программу, изучите условия факультета и начните готовиться к вступительному экзамену (`prijemni ispit`). Как подать документы, признать аттестат и участвовать в конкурсе иностранцу, описано в статье [Высшее образование в Сербии](/edu/university/).

## С чего начинать

1. На сайте факультета найдите разделы «Поступление» (`Upis`), «Конкурс» (`Konkurs`) и «Вступительный экзамен» (`Prijemni ispit`). Выберите нужную программу и год набора.
2. Выпишите предметы, темы, формат испытаний, критерии оценки и разрешённые принадлежности. Уточните, есть ли отдельная проверка языка.
3. Найдите сборник задач и варианты прошлых лет, опубликованные факультетом. Сравните их с актуальной программой конкурса.
4. Проверьте, организует ли факультет подготовительные занятия (`pripremna nastava`), и уточните условия записи.
5. Решите пробный вариант с ограничением по времени. Разберите ошибки отдельно по предмету и по пониманию сербских формулировок.

Сборник прошлых лет помогает тренироваться, но не определяет правила нового конкурса.

## Каталог Читавука

[Материалы для поступления](https://citavuk.ru/materials) — открытый указатель независимого проекта Дениса Корнилова «Читавук». В нём собраны ссылки на сотни документов для специализированных гимназий и вузов: экзамены прошлых лет, ключи, решения, пособия. Можно искать по предмету, году и учреждению. Документы открываются по ссылкам на издателей либо в читалке Читавука с языковыми подсказками.[^1]

Для подготовки к высшему образованию выберите категорию «Университет». В каталоге есть материалы по математике, химии, биологии, физике, информатике и социологии, но представлены не все факультеты. Часть материалов относится к конкретным направлениям.

Если войти в аккаунт, можно составить по документу тренировочный тест с помощью языковой модели. Проверяйте такие вопросы и ответы по оригинальному заданию и официальному ключу: сгенерированный тест не является экзаменом факультета.[^1]

## Прямые источники факультетов

| Учреждение | Где искать |
| --- | --- |
| Математический факультет, Белград | [Раздел поступления на бакалавриат](https://www.matf.bg.ac.rs/upis-oas/) |
| Химический факультет, Белград | [Архив задач для вступительного экзамена](https://www.chem.bg.ac.rs/upis/zadaci.html) |
| Факультет технических наук (FTN), Нови-Сад | [Сборники и литература](https://ftn.uns.ac.rs/zbirka-zadataka-i-literatura/) |

На странице FTN также доступны разделы о порядке экзамена, математических темах и подготовительных занятиях. Используйте меню текущего набора.[^2][^3][^4]

[Prijemni ispit — платформа Математического факультета Белградского университета](https://prijemniispit.matf.bg.ac.rs/) содержит задачи по математике и сербскому языку для подготовки к вступительным испытаниям. Можно решать пробные тесты и упражнения по темам и уровням; задания сгруппированы с учётом разных факультетов.[^5]

Для других направлений найдите учреждение через каталог Читавука или список университетов в [основной статье](/edu/university/), затем проверьте актуальные материалы на сайте факультета.

## Предметный сербский

Даже при хорошем бытовом сербском трудности могут возникать из-за терминов и инструкций. Соберите свой словарь по реальным экзаменационным заданиям.

| Сербский | Русский |
| --- | --- |
| `zadatak` | задача, задание |
| `rešenje` | решение |
| `tačan odgovor` | правильный ответ |
| `zaokružiti` | обвести вариант ответа |
| `izračunati` | вычислить |
| `dokazati` | доказать |
| `odrediti` | определить |
| `obrazložiti` | обосновать |
| `prikazati postupak` | показать ход решения |
| `bodovi` | баллы |

Сначала прочитайте условие без перевода. Затем проверьте незнакомые термины, решите задание и сравните ход решения с ключом. При повторении попробуйте объяснить решение по-сербски. Открывайте учебники и файлы PDF в [читалке Читавука](https://citavuk.ru/). Автоматический перевод предметных терминов проверяйте по учебнику.

Если требуется подтверждение знания языка, см. [Экзамены и сертификаты по сербскому языку](/edu/serbian-exams/).

Для поступления в специализированную гимназию используйте отдельные инструкции: [Поступление в среднюю школу](/edu/school/secondary-admission/) и [Школьные ресурсы](/edu/school/resources/).
