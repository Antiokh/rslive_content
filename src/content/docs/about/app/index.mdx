«Инструкцию по Сербии» можно использовать просто как сайт, установить как приложение и, отдельно, сохранить полную копию материалов для работы без интернета. Это три разных режима: установка приложения сама по себе не скачивает всю энциклопедию.

## Установка приложения

Если браузер поддерживает установку, RSLive может предложить добавить «Инструкцию по Сербии» как приложение. После установки она открывается в отдельном окне и выглядит как обычное приложение на телефоне или компьютере.

Без офлайн-копии приложение занимает немного дополнительного места: основное содержимое по-прежнему загружается из интернета по мере открытия страниц.

Установка приложения не означает автоматическое скачивание всего сайта. Офлайн-копию можно включить отдельно.

## Офлайн-копия

Офлайн-копия нужна, если вы хотите читать RSLive там, где интернет слабый, дорогой или недоступен: например, в дороге или при проблемах со связью.

Перед скачиванием сайт показывает актуальный размер полной копии. Размер меняется вместе с энциклопедией, поэтому на этой странице нет фиксированной цифры.

В полную копию входят страницы сайта, поиск, необходимые для работы сайта файлы и собственные картографические данные RSLive. Некоторые карты и другие материалы внешних сервисов могут оставаться доступными только через интернет, если у RSLive нет собственной офлайн-копии этих данных.

Пока полная офлайн-копия не скачана, установленное приложение продолжает работать как обычный сайт и ничего большого автоматически не загружает.

## Как скачивается первая копия

После вашего согласия RSLive собирает новую офлайн-копию отдельно от той версии, которой вы сейчас пользуетесь. Копия считается готовой только после того, как все необходимые файлы действительно сохранены.

Если интернет пропал или отдельный файл временно не загрузился, незавершённая копия не подменяет рабочую. Загрузка может быть продолжена позже.

## Как обновляется офлайн-копия

RSLive не скачивает весь сайт заново при каждом изменении.

Сначала сайт получает небольшой служебный список и проверяет, какие файлы изменились. Всё, что осталось прежним, берётся из уже сохранённой копии на вашем устройстве. Из интернета загружаются только новые и изменённые страницы и файлы.

Если изменилась одна статья и больше ничего связанного с ней не изменилось, по сети загружается новая версия этой статьи плюс небольшой служебный список обновления. По объёму трафика это практически то же самое, что один раз открыть новую версию этой страницы в обычном режиме: вся остальная энциклопедия повторно не скачивается.

Если вместе со статьёй изменились необходимые общие файлы или собственные данные карты, они тоже будут загружены. Неизменённые файлы повторно через интернет не передаются.

Новая версия сначала собирается отдельно. Старая рабочая офлайн-копия остаётся доступной, пока обновление не будет полностью готово. Только после успешного завершения RSLive переключается на новую копию.

## Автообновление

Если автообновление включено, RSLive периодически проверяет, появилась ли новая версия офлайн-копии. Сама проверка маленькая и не скачивает энциклопедию целиком.

Когда обновление найдено, оно устанавливается без дополнительного вопроса. При этом действует тот же экономный порядок: уже сохранённые и не изменившиеся файлы используются с устройства, а через интернет загружаются только новые или изменённые.

Автообновление можно выключить. Уже сохранённая офлайн-копия от этого не удаляется.

## Если автообновление выключено

Если сохранённая копия устарела, RSLive может предложить обновить её. Такое предложение показывается не чаще одного раза в календарный день.

Пока вы не согласились на обновление, старая копия остаётся доступной. Она может не содержать последние изменения сайта, но не удаляется только из-за появления новой версии.

## Что происходит без интернета

При обычной работе RSLive сначала старается открыть свежую страницу из интернета. Если сети нет и полная офлайн-копия готова, сайт использует сохранённую версию.

Поэтому офлайн-режим не меняет привычный способ чтения сайта при нормальном соединении: когда интернет есть, вы получаете актуальные материалы; когда его нет, используется сохранённая копия.

## Как удалить офлайн-копию

Офлайн-данные можно удалить из настроек RSLive. Удаление офлайн-копии не удаляет само установленное приложение.

После удаления приложение снова работает как обычный сайт и загружает страницы из интернета по мере необходимости. При желании полную копию можно скачать заново.
