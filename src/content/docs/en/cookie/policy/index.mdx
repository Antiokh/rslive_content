# Privacy Policy

RSLive (rslive.ru) is a public encyclopedia. Registration is not required to read its materials, and the website does not create user profiles.

## Data processed

When you visit the website, technical data normally transmitted by the browser and website infrastructure may be processed, including IP address, user-agent, request time, pages visited, and technical information about website operation.

The following services are used to analyze website traffic and operation:

- Google Tag Manager;
- Google Analytics;
- Yandex Metrica.

These services may receive technical information about the device, browser, referral source, pages viewed, and interactions with the website according to the settings of the respective services.

RSLive does not use website user registration, personal accounts, profiles, or its own system for collecting visitors' personal data.

## Purposes of processing

Technical and statistical data are used to:

- measure traffic and demand for materials;
- analyze page and navigation performance;
- detect technical errors;
- improve website structure and content;
- protect and maintain the infrastructure.

RSLive does not sell visitor data or use it to create its own advertising profiles.

## Third-party services

Processing performed by Google Tag Manager, Google Analytics, and Yandex Metrica is also governed by the rules and policies of the respective providers. The scope and retention period of such data depend on the configuration and current rules of those services.

## Retention

RSLive does not set a separate retention period in its own user database because no such visitor database is maintained. Infrastructure logs and statistics held by external analytics services may be retained according to the settings and policies of the respective providers.

## Data questions

If you have a question about data processing on rslive.ru, contact the RSLive editors via [Telegram](https://t.me/rslive_ru).

## Changes to this policy

This policy may be updated if the infrastructure or analytics services used by the website change. The current version is always published on this page.
