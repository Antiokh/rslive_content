# Privacy Policy

RSLive (rslive.ru) is a public encyclopedia. Registration is not required to read its materials, and the website does not create user profiles or personal accounts.

The website nevertheless uses technical browser storage for interface settings and, when selected by the user, application and offline data. Separate analytics services are used to understand website traffic and operation.

## Data processed

When you access the website, infrastructure may process technical data normally transmitted with a network request, including IP address, user-agent, request time, the address of the page opened, and technical information about website operation.

The following services are used to analyze website traffic and operation:

- Google Tag Manager;
- Google Analytics;
- Yandex Metrica.

In its default web implementation, Google Analytics can collect user and session counts, approximate geolocation, and browser and device information; it uses the first-party `_ga` cookie to distinguish users and sessions when analytics storage is enabled.[^1] Yandex Metrica uses anonymous browser identifiers that can be stored in cookies and `localStorage` to produce traffic and behavior statistics.[^2]

RSLive does not operate its own visitor registration system and does not store login or authorization data for reading the encyclopedia.

## Data stored on your device

Depending on which functions you use, the browser may store:

- the selected display theme;
- the expanded or collapsed state of sidebar sections;
- confirmation that the cookies and storage notice has been read;
- the local date of the latest standalone application launch;
- a local marker recording whether an application, offline-download or manual update offer was shown on the current calendar day;
- the user's offline auto-update preference;
- information about the presence and freshness of an existing offline copy;
- temporary session data;
- the complete offline copy itself, if the user explicitly chooses to download it.

RSLive uses ordinary browser mechanisms for this purpose, including cookies, `localStorage`, `sessionStorage`, Cache Storage and a service worker. Locally stored interface or offline settings do not by themselves constitute a user account.

## Cookies and the storage notice

If the acknowledgement marker is absent, RSLive shows a notice about cookies and local storage on each page. Until the notice is acknowledged, the website does not show subsequent product prompts to install the application, download the complete offline copy or manually update it.

The “Got it” action records that the notice has been read. It does not create an account or turn local technical settings into a user profile.

If the browser blocks or clears website storage, settings may not persist, an offline copy may become unavailable, and the notice may be shown again.

## Purposes of processing

Local technical data is used to:

- preserve interface settings;
- limit application and offline-mode prompts to no more than once per local calendar day;
- determine whether the standalone application was actually launched on the current day;
- store and update the offline copy;
- use a ready offline copy when the network is unavailable.

Technical and statistical data handled by external services is used to:

- measure traffic and demand for materials;
- analyze page and navigation performance;
- detect technical errors;
- improve website structure and content;
- protect and maintain the infrastructure.

RSLive does not maintain its own advertising profile database for visitors.

## Third-party services

Google Tag Manager is used to load and manage tags. Google Analytics and Yandex Metrica may store their own cookies or identifiers and receive technical information about visits according to the actual configuration of the counters and the providers' current rules.[^1][^2]

Because external analytics is used, RSLive should not be described as a website that “tracks nothing and stores only settings”. Serbian personal-data law requires an appropriate legal basis for processing; Article 12 provides several possible legal bases, of which consent is only one.[^3]

## Retention

Local settings normally remain until they are changed or removed, website data is cleared in the browser, or RSLive changes the technical format of a setting.

Session data may disappear when the session ends. A complete offline copy remains in browser storage until the user removes it, browser site data is cleared, or the browser removes stored data under its own storage-management policy.

RSLive does not state one universal retention period for statistics held by external analytics providers: actual periods depend on the service configuration and the provider's current rules.

## Removing local data

The complete offline copy can be removed separately through RSLive controls. Removing it does not uninstall the application itself.

Cookies, `localStorage`, `sessionStorage` and other site data can also be cleared through browser controls. After a full clear, RSLive will treat that browser as new: the theme and other preferences can reset and the cookies/storage notice can appear again.

## Data questions

If you have a question about data processing on rslive.ru or believe RSLive processes personal data relating to you, contact the editors via [Telegram](https://t.me/antiokh). Do not post sensitive personal data in a public GitHub issue.

Depending on the circumstances, Serbian personal-data law provides rights including access, rectification and completion, erasure, restriction, portability and objection. If contacting the controller does not resolve the matter, the data subject may lodge a complaint with the Commissioner for Information of Public Importance and Personal Data Protection.[^4]

## Changes to this policy

This policy may be updated if the infrastructure, analytics services or application behavior changes. The current version is always published on this page.

As checked on 24 August 2026, the Commissioner's current materials still refer to the Personal Data Protection Act (`Official Gazette of the Republic of Serbia`, No. 87/2018), while the Ministry of Justice is conducting a public consultation on a draft new act from 30 July to 10 September 2026. The draft is not presented here as law already in force.[^3][^5]
