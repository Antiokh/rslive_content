You can use RSLive (Guide to Serbia) as a website, install it as an app, and separately save a complete copy of its materials for offline use. These are three different modes: installing the app does not download the entire encyclopedia.

## Installing the app

If your browser supports installation, RSLive may offer to add the site as an app. Once installed, it opens in a separate window and looks like a regular app on your phone or computer.

Without an offline copy, the app takes up little additional space: most content is still downloaded from the internet as you open pages.

Installing the app does not automatically download the entire site. You can enable the offline copy separately.

## Offline copy

An offline copy lets you read RSLive where internet access is weak, expensive or unavailable, such as while travelling or during connection problems.

Before downloading, the site displays the current size of the full copy. This changes as the encyclopedia grows, so no fixed figure is given here.

The full copy includes site pages, search, the files needed to run the site and RSLive's own map data. Some maps and other materials from external services may still require internet access if RSLive has no offline copy of that data.

Until the complete offline copy is downloaded, the installed app continues to work like a regular website and does not automatically download large amounts of data.

## How the first copy is downloaded

After you give consent, RSLive assembles a new offline copy separately from the version you are currently using. The copy is ready only after all required files have actually been saved.

If the internet connection drops or a file temporarily fails to download, the incomplete copy does not replace a working one. The download can be resumed later.

## How the offline copy is updated

RSLive does not download the entire site again whenever something changes.

First, the site retrieves a small update manifest and checks which files have changed. Everything unchanged is reused from the copy already saved on your device. Only new or changed pages and files are downloaded.

If one article changes and no associated files change, only the new version of that article and the small update manifest are transferred. The amount of data is roughly the same as opening that new version once in normal browsing mode: the rest of the encyclopedia is not downloaded again.

If required shared files or RSLive's own map data change alongside the article, they are downloaded too. Unchanged files are not transferred again.

The new version is assembled separately. The old working offline copy remains available until the update is completely ready. RSLive switches to the new copy only after the update succeeds.

## Automatic updates

When automatic updates are enabled, RSLive periodically checks whether a new offline version is available. The check itself is small and does not download the whole encyclopedia.

When an update is found, it is installed without asking again. The same efficient process applies: unchanged files are reused from the device, and only new or changed files are downloaded.

You can turn off automatic updates. This does not delete your existing offline copy.

## When automatic updates are disabled

If your saved copy is outdated, RSLive may offer to update it. This offer is displayed no more than once per calendar day.

Until you agree to update, the old copy remains available. It may not contain the latest changes, but it is not deleted merely because a new version exists.

## What happens without internet access

In normal use, RSLive first tries to open the latest page from the internet. If there is no connection and the full offline copy is ready, the site uses the saved version.

Offline mode therefore does not change how you normally read the site with a working connection: when internet access is available, you receive current materials; without it, the saved copy is used.

## Removing the offline copy

You can remove offline data from the RSLive settings. Removing the offline copy does not uninstall the app itself.

After removal, the app works like a normal website again, downloading pages from the internet as needed. You can download the full copy again if you wish.

## Privacy and local settings

RSLive stores technical settings on your device that are needed for your chosen mode, such as the offline copy status and the automatic update setting. For general information about cookies, local storage and visitor statistics, see the [Privacy Policy](/en/about/privacy/).
