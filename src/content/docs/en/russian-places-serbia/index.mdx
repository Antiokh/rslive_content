## What is shown in each card

For each published place, the map shows its name, city, address, editorial description and a Google Maps link. The map interface and editorial descriptions are shown in English on this page.

The dataset categories are **cafés and restaurants**, **bars** and **shops**. If a place closes or its data no longer passes editorial review, it should not remain in the public dataset merely because it used to appear in an external source.

## Freshness

<Aside type="caution" title="Check before you travel">
  Places can move, change their opening hours or close. Before making a long trip, open the Google Maps link in the place card and check its current status.
</Aside>
