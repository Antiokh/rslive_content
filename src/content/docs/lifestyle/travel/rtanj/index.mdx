Ртань (`Rtanj`) — горный массив в восточной Сербии между муниципалитетами Сокобаня и Болевац. Вершина Шиляк (`Šiljak`) высотой **1570 м** находится в специальном природном резервате `Specijalni rezervat prirode „Rtanj”`.[^1]

Для первого подъёма используйте размеченный маршрут Planinarski savez Srbije (PSS) и заранее скачайте его GPX. Не стройте основной трек по случайной записи из приложения: на Ртане есть несколько вариантов подъёма с разной длиной, набором высоты, доступом к воде и точками старта.

## Кратко

- для сквозного маршрута используйте **Mirovo → Šiljak → selo Rtanj**: 13,7 км, около 7 часов, набор 1207 м, сложность `zahtevna`;[^2]
- для кольцевого маршрута от `Tomićeva koliba` используйте **Grebenom Rtnja**: 13,3 км, около 7 часов, набор 869 м, сложность `srednje teška`;[^3]
- на маршруте из Mirovo PSS отмечает два источника питьевой воды; на кольце от Tomićeva koliba питьевых источников нет;[^2][^3]
- оба маршрута размечены красно-белой планинарской маркировкой и имеют GPX на сайте PSS;[^2][^3]
- проверяйте прогноз непосредственно перед выходом и рассчитывайте время так, чтобы завершить маршрут засветло.

<Aside type="caution" title="Вода зависит от выбранной трассы">
  Не переносите описание одного маршрута на другой. На трассе Mirovo → Šiljak → Rtanj PSS указывает два источника питьевой воды, а на кольцевом маршруте Grebenom Rtnja — ни одного. Для кольца несите весь необходимый запас с собой.[^2][^3]
</Aside>

## Вариант 1. Mirovo → Šiljak → Rtanj

PSS описывает маршрут с началом у каменоломни `Unimer` возле Mirovo и окончанием в селе Rtanj.[^2]

| Параметр | Значение |
| --- | --- |
| Длина | 13,7 км |
| Время | около 7 часов |
| Старт | карьер `Unimer`, Mirovo, 363 м |
| Финиш | село Rtanj, 599 м |
| Набор / сброс | 1207 / 971 м |
| Сложность PSS | `zahtevna` — сложная |
| Маркировка | стандартная красно-белая |
| Питьевая вода | 2 источника на трассе |
| GPX | опубликован PSS |

Первая часть идёт по дороге и лесным тропам. После выхода на седло маршрут продолжается по гребню к Шиляку; спуск проходит по южной стороне через перевал `Baba` к селу Rtanj.[^2]

Это **не кольцевой** маршрут. До выхода решите, как вернётесь к автомобилю или месту ночёвки после финиша в другой точке.

### Кому подходит

Выбирайте этот вариант, если готовы к набору более 1200 м и заранее решили транспортный вопрос между стартом и финишем. PSS прямо классифицирует трассу как сложную и отдельно указывает необходимость осторожности.[^2]

## Вариант 2. Grebenom Rtnja

Кольцевая трасса начинается и заканчивается у `Tomićeva koliba`. До неё PSS указывает около 6,5 км по грунтовой дороге от села Mužinac.[^3]

| Параметр | Значение |
| --- | --- |
| Длина | 13,3 км |
| Время | около 7 часов |
| Старт / финиш | `Tomićeva koliba`, 834 м |
| Набор / сброс | 869 / 869 м |
| Сложность PSS | `srednje teška` — средней сложности |
| Маркировка | стандартная красно-белая |
| Питьевая вода | нет |
| GPX | опубликован PSS |

Маршрут выходит на западную часть массива, проходит по гребню через Kusak и Preslo к Шиляку и возвращается по классическому серпантинному спуску.[^3]

Кольцо удобнее логистически, но не означает прогулочный формат: PSS закладывает те же семь часов движения, а воды на трассе нет.[^3]

## Как подготовиться

<Steps>
1. **Выберите конкретный маршрут.** Не ограничивайтесь целью «подняться на Ртань»: определите старт, финиш и способ возвращения.
2. **Скачайте GPX с PSS.** Сохраните трек офлайн и не полагайтесь только на мобильную связь.
3. **Проверьте прогноз.** Смотрите погоду для массива и вершины, а не только для Сокобани или Болеваца.
4. **Рассчитайте воду.** Для маршрута без источников несите полный запас; наличие отмеченного источника не отменяет резерв воды.
5. **Возьмите подходящую обувь и дополнительный слой одежды.** На гребне меньше защиты от погодных изменений, чем в лесной части маршрута.
6. **Начните достаточно рано.** Официальные карточки обеих трасс дают ориентир около семи часов без учёта вашей дороги к старту, длительных остановок и непредвиденных задержек.[^2][^3]
7. **Не сходите с размеченной трассы без причины.** Ртань — охраняемая природная территория; соблюдайте режим резервата и указания на местности.[^1]
</Steps>

## Что совместить с поездкой

Ртань относится к туристическому региону Сокобани. Туристическая организация Сокобани отдельно выделяет Ртань среди горных направлений района и относит его к более требовательным вариантам по сравнению с прогулочными маршрутами на Озрене, Девице и Буковике.[^4]

Если подъём занимает основной день, не добавляйте после него насыщенную программу. Сокобаню, термы или другие точки района удобнее оставить на следующий день.
