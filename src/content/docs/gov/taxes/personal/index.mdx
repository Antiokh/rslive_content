Этот раздел — про налоги физического лица, а не зарегистрированного бизнеса как такового. Для налогового резидента Сербии важно учитывать не только сербские, но и иностранные доходы: закон распространяет налогообложение резидента на доход, полученный в Сербии и другой стране.[^1]

## Что читать

| Доход | Страница |
| --- | --- |
| Зарплата | [Налог с зарплаты](/gov/taxes/personal/salary/) |
| Работа/услуги без сербского удерживающего плательщика | [Фриланс](/gov/taxes/personal/freelance/) |
| Доход от иностранной компании, капитала или аренды | [Иностранные доходы](/gov/taxes/personal/foreign-income/) |
| Высокий совокупный годовой доход | [Годовой налог](/gov/taxes/personal/annual-income/) |
| Дивиденды | [Дивиденды](/gov/taxes/business/dividends/) |
| Продажа акций, недвижимости, долей, криптоактивов | [Капитальный доход и прирост](/gov/taxes/assets/capital-gains/) |

<Aside type="note" title="Сначала определите налоговое резидентство">
  Сербское РВП само по себе не отвечает на вопрос о налоговом резидентстве. Закон использует критерий места жительства/центра жизненных и деловых интересов и отдельный критерий 183 дней.[^1]
</Aside>
